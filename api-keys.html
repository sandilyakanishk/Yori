How to Get Your
Free API Keys.

Yori needs two free keys to work: one for the AI Brain (NVIDIA), one for Web Search (Tavily).

1. NVIDIA API Key (AI Brain)

Get NVIDIA Key
  1. Go to build.nvidia.com and create a free account or log in.
  2. Open the model catalog and find meta/llama-3.1-8b-instruct.
    (The model Yori uses by default — chosen for its speed).
  3. Click "Get API Key" or "Generate Key" on that model's page.
  4. Copy the generated key.
  5. In the Yori app: go to Settings → API Configuration → NVIDIA API and paste the key.
Also supported in Yori: meta/llama-3.1-70b-instruct, meta/llama-3.3-70b-instruct, nvidia/llama-3.3-nemotron-super-49b-v1.5, meta/llama-3.2-11b-vision-instruct, meta/llama-3.2-90b-vision-instruct, meta/llama-3.2-3b-instruct.

2. Tavily API Key (Web Search)

Get Tavily Key
  1. Go to tavily.com and sign up for a free account.
  2. Open your developer dashboard and find the API Keys section.
  3. Generate a new key and copy it.
  4. In the Yori app: open Settings and try to toggle on Internet Access. Since this toggle defaults off and requires a key, the app will prompt you to paste your Tavily key at that point. Enter it and confirm — Internet Access will then turn on.
